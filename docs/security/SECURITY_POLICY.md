## Secure Development Practices

To maintain the integrity of RamaLama, all contributions adhere to standard secure coding practices:
- **Peer Review & Testing**: All patches and security fixes undergo mandatory peer review by maintainers and regression testing prior to merging.
- **Maintainer Controls**: Maintainers oversee triage, patch verification, CVE requests, and disclosure coordination.
